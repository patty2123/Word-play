# Word Hunt

A word-hunting game on a 3×3, 4×4 or 5×5 board. Drag across touching letters to
spell words — longer words score much more.

Every board is fully solved before it's shown, so you never get a dud grid, and
when the round ends you can see every word that was there and tap any of them to
trace where it was hiding.

Plays in any browser. On iPhone, use Share → Add to Home Screen for a fullscreen
app that works offline.
